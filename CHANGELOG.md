# Changelog

## 1.0.0 – 2026-11-09

First release.

- Notion-style pages (BlockNote) stored as Markdown, with autosave, editable titles, print/PDF and Markdown export.
- Notepad++-style code editor (Monaco, bundled for offline use) with tabs, status bar, find/replace, wrap, whitespace, EOL and language switching.
- Excalidraw whiteboards stored as `.excalidraw` files, with SVG previews embeddable in pages via `/whiteboard`.
- File tree with folders, drag-to-move, inline rename, right-click menu and soft delete to `.trash`.
- Quick open, full-text search, zip export, light/dark theme, tab session restore.
- Docker image with healthcheck, published to GHCR for amd64 and arm64.
